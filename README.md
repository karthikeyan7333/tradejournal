# 📈 TradeJournal – Personal Trading Journal

**Track Every Trade. Analyze Your Performance. Become a Better Trader.**

TradeJournal is a personal trading journal application designed to help traders record their trades, monitor profit and loss, analyze trading performance, and learn from their trading decisions.

Whether you trade stocks, options, forex, or cryptocurrency, TradeJournal helps you maintain a structured record of your trading journey.

## ✨ Features

- 🔐 **User Authentication** – Secure login and signup.
- 📝 **Trade Recording** – Record entry price, exit price, lot size, profit and loss, and other trade details.
- 📊 **Performance Analytics** – Visualize trading performance through charts and statistics.
- 📅 **Trading Calendar** – View profitable and losing days using green and red indicators.
- 📸 **Image Uploads** – Attach chart screenshots and trade references.
- 📈 **Multiple Markets** – Track Indian Stocks, Options, Forex, Crypto, and other markets.
- 💭 **Trade Analysis Notes** – Record lessons learned and observations from each trade.
- 📱 **Responsive Design** – Use the application on desktop and mobile devices.
- ☁️ **Cloud Data Storage** – Access your trading journal across devices using your account.

## 🛠️ Tech Stack

## 🚀 Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/karthikeyan7333/tradejournal.git
```

### 2. Navigate to the project directory

```bash
cd tradejournal
```

### 3. Install dependencies

```bash
npm install
```

### 4. Configure environment variables

Create a `.env.local` file and add the required API configuration:

```env
GEMINI_API_KEY=your_gemini_api_key
```

Configure your Firebase project credentials according to the application's Firebase configuration.

**Important:** Never upload API keys, private credentials, or secret environment files to GitHub.

### 5. Run the development server

```bash
npm run dev
```

Open the local URL displayed in your terminal.

## 🎯 Project Objective

TradeJournal aims to help traders develop discipline, maintain consistency, understand their trading behavior, and improve their decision-making through proper trade documentation and performance tracking.
